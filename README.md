# hermes-windows-offline

非官方合集：前端设计 skill、Hermes Agent 的 Windows 离线安装包，以及离线宠物资源。

## 设计 skills

- [frontend-design](skills/frontend-design/)：避免千篇一律默认风格的界面设计指导。
- [ui-ux-pro-max](skills/ui-ux-pro-max/)：带本地检索脚本与数据的 UI/UX 设计参考。

用法与限制见 [docs/skills.md](docs/skills.md)。

## Windows 离线安装

官方稳定版桌面 0.22.0 侧载包，需 Windows 11 22H2 或更高。请到 [Release official-stable-0.22.0](https://github.com/chenzhuyu2004/hermes-windows-offline/releases/tag/official-stable-0.22.0) 下载分片或 ZIP，再按 [安装说明](docs/offline-install.md) 拼合、校验后安装；不要用仓库的 Source code zip。

## 宠物资源

给已安装 0.22.0 桌面的离线入门包（五只，约 9 MB）：[下载 Hermes-Pets-Offline-for-0.22.0.zip](https://github.com/chenzhuyu2004/hermes-windows-offline/releases/download/official-stable-0.22.0/Hermes-Pets-Offline-for-0.22.0.zip)。拷贝位置与许可见 [宠物说明](docs/pets.md)。

本仓库与 Nous Research、Anthropic、Next Level Builder 均无隶属或代言关系。许可见 [LICENSING.md](LICENSING.md)。
